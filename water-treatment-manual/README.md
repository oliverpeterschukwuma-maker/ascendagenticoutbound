# Water Treatment Site-Specific Operating Manual

**Status:** Living document — updated continuously as new information is provided.  
**Audience:** Operators with no prior water treatment experience.  
**How to use:** Start with Section 0 (Orientation), then read sections in order. Return to any section whenever you need a refresher.

---

## How to Add Information

Drop any of the following into the `uploads/` folder and tell the assistant:
- PDFs, Word docs, or text files (SOPs, manuals, permits)
- Photos or diagrams (process flow, equipment labels, P&IDs)
- Handwritten notes (scan or photograph them)
- Anything your trainer or supervisor gave you

The assistant will read every file and update the relevant sections of this manual automatically.
