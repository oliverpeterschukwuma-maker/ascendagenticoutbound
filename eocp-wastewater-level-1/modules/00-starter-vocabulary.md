**Why this module exists:** The exam uses many words that sound strange at first. If you don't know the words, every question feels hard — even easy ones. This module teaches the **words first**, in plain English, so every other module makes sense.

**How to use it:**
1. Read one section per day (about 15–20 minutes).
2. Cover the "Plain meaning" column with your hand and test yourself.
3. Come back to this page whenever a module uses a word you forgot.
4. Do the 25-question quiz at the end. Aim for 22+.

## Part A — Word parts (learn these and you can guess 100 other words)

Many wastewater words are built from small pieces. Learn the pieces and you can figure out words you've never seen.

| Word part | Means | Examples |
|---|---|---|
| **aero / aer** | air, oxygen | **aer**obic (with oxygen), **aer**ation (adding air) |
| **an / a** | without, not | **an**aerobic (without oxygen), **a**septic |
| **anoxic** | no free oxygen, but nitrate present | anoxic zone |
| **bio** | life, living | **bio**logical, **bio**solids, **bio**film |
| **in-** | into | **in**fluent (flowing in), **in**filtration |
| **ef- / ex-** | out of | **ef**fluent (flowing out) |
| **-fluent** | flowing | in**fluent**, ef**fluent** |
| **hydr / hydro** | water | **hydr**aulic, **hydro**gen sulphide |
| **-meter** | measures | flow**meter**, pH **meter** |
| **-cide** | kills | bio**cide**, germi**cide** |
| **de-** | remove, reverse | **de**chlorination (remove chlorine), **de**nitrification, **de**watering |
| **-ification** | the process of making | nitr**ification** (making nitrate), clar**ification** (making clear) |
| **clar** | clear | **clar**ifier (tank that makes water clear) |
| **sub / sub-** | under | **sub**mersible pump (works under water) |
| **thermo / thermal** | heat | **thermo**philic (heat-loving), thermometer |
| **meso** | middle | **meso**philic (medium temperature, ~35 °C) |
| **-philic** | loving | thermo**philic** (heat-loving bacteria) |
| **volatile** | burns off / evaporates | **volatile** solids (organic part that burns off) |
| **septic** | rotten, no oxygen | **septic** wastewater (black, smells like rotten eggs) |
| **putrescible** | can rot | putrescible solids |
| **turbid / turbidity** | cloudy | high **turbidity** = cloudy water |

## Part B — Plant & flow words

| Term | Plain meaning | Memory hook / example |
|---|---|---|
| **Wastewater** | Used water from homes, businesses, industry (plus rain/groundwater that leaks in) | "Sewage" is the older word |
| **WWTP** | Wastewater Treatment Plant | Where you'll work |
| **Influent** | Water flowing **in** | **I**n = **I**nfluent |
| **Effluent** | Water flowing **out** | **E**xit = **E**ffluent |
| **Headworks** | The very first part of the plant (screens, grit removal, flow meter) | The "head" = the front |
| **Collection system** | Sewer pipes and lift stations that bring wastewater to the plant | Not part of your *treatment* exam except where it affects the plant |
| **Lift station / pump station** | Pumps that lift wastewater uphill | Has a **wet well** |
| **Wet well** | Underground tank where wastewater collects before being pumped | A confined space! |
| **Force main** | Pressurized pipe that a pump pushes wastewater through | vs gravity sewer |
| **Gravity sewer** | Pipe that slopes downhill so water flows by itself | |
| **Unit process** | One step of treatment (e.g., screening is one unit process) | |
| **Preliminary treatment** | Removes big stuff and grit to protect equipment | Step 1 |
| **Primary treatment** | Settles solids and skims floating material | Step 2 |
| **Secondary treatment** | Uses bacteria to eat dissolved organics | Step 3 |
| **Tertiary / advanced treatment** | Extra polishing (filters, nutrient removal) | Step 4 (some plants) |
| **Disinfection** | Kills or inactivates germs before discharge | Chlorine or UV |
| **Receiving water / receiving environment** | Where the treated effluent goes (river, lake, ocean, ground) | |
| **Outfall** | The pipe that carries effluent into the receiving water | |
| **Bypass** | Flow that goes **around** a treatment unit (or the whole plant) | Usually must be reported |
| **Overflow (SSO)** | Sewage spilling out of the sewer/plant before treatment | Sanitary Sewer Overflow; must be reported |
| **I/I (Infiltration & Inflow)** | Groundwater and rain getting into sewers | Raises flow in wet weather |
| **Diurnal** | Changing over a day | Flow is low at night, high in morning/evening |
| **Peak flow** | The highest flow | Storms, mornings |
| **Detention time (DT) / HRT** | How long water stays in a tank | "How long it sits" |
| **Short-circuiting** | Water takes a shortcut through a tank, so it doesn't stay long enough | |
| **Weir** | A wall/edge that water flows over (often V-notched) | Clarifier outlets |
| **Launder** | The trough that collects water after it flows over the weir | |
| **Baffle** | A wall/plate that directs flow | |
| **Septage** | Waste pumped out of septic tanks and trucked in | Very strong |
| **Supernatant** | The liquid on top after solids settle | From digesters, settleometer |
| **Recycle / return streams** | Liquid sent back to the start of the plant (from thickeners, digesters, dewatering) | Can add load |

## Part C — Water-quality words (the things we measure)

| Term | Plain meaning | Why an operator cares |
|---|---|---|
| **Parameter** | Something you measure | BOD, TSS, pH are parameters |
| **mg/L** | milligrams per litre — how much stuff is in the water | Same as **ppm** (parts per million) in water |
| **Concentration** | How strong (how much per litre) | mg/L |
| **Load / loading** | How much total stuff per day | kg/day or lb/day |
| **BOD** | Biochemical Oxygen Demand — how much oxygen **bacteria** need to eat the organic "food" in the water (5 days, 20 °C) | Measures strength of wastewater |
| **CBOD** | Carbonaceous BOD — BOD without the ammonia part | Often used in permits |
| **COD** | Chemical Oxygen Demand — oxygen needed when a **strong chemical** breaks down organics | Fast test; COD is always bigger than BOD |
| **Organic** | Made of carbon; from living things; can rot | Food, feces, paper |
| **Inorganic** | Not from living things; mineral | Sand, grit, salt |
| **Solids** | Anything that isn't water | |
| **TSS** | Total Suspended Solids — solids that a filter catches | Cloudiness, sludge |
| **TDS** | Total Dissolved Solids — solids dissolved in water (pass through filter) | Salts |
| **VSS** | Volatile Suspended Solids — the organic part of TSS (burns at 550 °C) | Estimates bugs (biomass) |
| **Settleable solids** | Solids that sink in a cone in a set time | mL/L |
| **DO** | Dissolved Oxygen — oxygen gas dissolved in the water | Bugs and fish need it |
| **pH** | How acidic (low) or basic (high) — 7 is neutral | Bugs like ~6.5–8.5 |
| **Alkalinity** | Ability to resist a pH change ("pH shock absorber") | Nitrification uses it up |
| **Nutrients** | Nitrogen (N) and phosphorus (P) | Feed algae in rivers/lakes |
| **Ammonia (NH₃/NH₄⁺)** | Nitrogen from urine/feces; toxic to fish | Removed by nitrification |
| **Nitrite (NO₂⁻)** | Middle step of nitrification | Short-lived |
| **Nitrate (NO₃⁻)** | End product of nitrification | Removed by denitrification |
| **TKN** | Total Kjeldahl Nitrogen = organic N + ammonia | |
| **Phosphorus (P)** | Nutrient that causes algae blooms | Removed by chemicals or special bacteria |
| **Eutrophication** | Too many nutrients → algae blooms → oxygen loss in lakes | Why we remove N and P |
| **Pathogen** | Germ that causes disease | Bacteria, viruses, protozoa, worms |
| **Coliform / *E. coli*** | Indicator bacteria — show sewage contamination | Used to check disinfection |
| **Turbidity** | Cloudiness | Measured in NTU |
| **ORP** | Oxidation-Reduction Potential — shows if conditions are oxygen-rich (+) or oxygen-poor (−) | Measured in mV |
| **Toxic** | Poisonous | Can kill the bugs |
| **FOG** | Fats, Oils and Grease | Clogs pipes, forms scum |

## Part D — Biology words

| Term | Plain meaning | Memory hook |
|---|---|---|
| **Microorganism ("bugs")** | Tiny living things (bacteria, protozoa) | The plant's workers |
| **Bacteria** | Single-celled organisms; do most of the treatment | Eat the BOD |
| **Protozoa** | Bigger single-celled organisms that eat bacteria | Indicators of sludge health |
| **Rotifers** | Tiny multi-celled animals; show older sludge | |
| **Aerobic** | With oxygen | "**Aer**" = air |
| **Anaerobic** | Without oxygen (and without nitrate) | "**An**" = without |
| **Anoxic** | No oxygen gas, but nitrate is there | Used for denitrification |
| **Facultative** | Can live with **or** without oxygen | Flexible bugs |
| **Biomass** | The total amount of bugs | |
| **Floc** | A clump of bacteria stuck together | Floc must settle! |
| **Activated sludge** | A process where bugs are kept in a tank with air and recycled from the clarifier | Most common secondary process |
| **Mixed liquor** | The bug + wastewater mix in the aeration tank | |
| **MLSS** | Mixed Liquor Suspended Solids — total solids in the aeration tank | "How much sludge" |
| **MLVSS** | Mixed Liquor **Volatile** SS — the organic/living part | "How many bugs" |
| **RAS** | Return Activated Sludge — settled sludge pumped **back** to aeration | "**R**eturn" |
| **WAS** | Waste Activated Sludge — extra sludge **removed** | "**W**aste = **W**ithdraw" |
| **F/M** | Food-to-Microorganism ratio — food in ÷ bugs available | Too high = hungry bugs overloaded; too low = starving |
| **SRT / sludge age / MCRT** | How long (days) bugs stay in the system | Old vs young sludge |
| **SVI** | Sludge Volume Index — how well sludge settles | High = bad settling (bulking) |
| **Settleometer** | Clear 1–2 L container to watch sludge settle for 30 min | |
| **Bulking** | Sludge that won't settle well (often filaments) | |
| **Filaments** | Bacteria that grow in long threads | Too many = bulking |
| **Rising sludge** | Sludge that settles then floats up with gas bubbles | Denitrification |
| **Nitrification** | Bacteria turn ammonia → nitrite → nitrate (needs oxygen) | |
| **Denitrification** | Bacteria turn nitrate → nitrogen gas (no oxygen) | |
| **Biofilm** | Slime layer of bugs growing on a surface | Trickling filters, RBCs |
| **Lagoon / pond** | Large earthen basin for treatment | Common in small towns |
| **Algae** | Tiny plants that make oxygen in sunlight | Help lagoons |
| **Trickling filter** | Rock/plastic media with biofilm; water trickles over it | |
| **RBC** | Rotating Biological Contactor — spinning discs with biofilm | |
| **SBR** | Sequencing Batch Reactor — one tank does fill, react, settle, decant | |

## Part E — Solids/sludge words

| Term | Plain meaning |
|---|---|
| **Sludge** | Settled solids removed from the water |
| **Primary sludge** | Sludge from the primary clarifier (raw, smelly) |
| **Scum** | Floating grease, oil, and debris |
| **Screenings** | Rags and debris caught by screens |
| **Grit** | Sand, gravel, eggshells — heavy stuff |
| **Thickening** | Removing some water to make sludge thicker |
| **Digestion** | Bugs breaking down sludge to make it stable and smaller |
| **Aerobic digestion** | Digestion with air |
| **Anaerobic digestion** | Digestion without air; makes methane gas |
| **Dewatering** | Removing lots of water to make a "cake" (belt press, centrifuge, drying beds) |
| **Cake** | Dewatered sludge — looks like wet soil |
| **Biosolids** | Treated, stabilized sludge that can be beneficially used (e.g., on land) |
| **% solids** | How much of the sludge is solid (1% solids = 10,000 mg/L) |
| **Polymer** | Chemical that helps solids clump for thickening/dewatering (very slippery when spilled) |

## Part F — Equipment words (39% of your exam is equipment — learn these well)

| Term | Plain meaning |
|---|---|
| **Pump** | Machine that moves liquid |
| **Centrifugal pump** | Uses a spinning **impeller** to throw water outward — most common |
| **Positive displacement (PD) pump** | Traps a fixed amount of liquid and pushes it (good for thick sludge) — **never run against a closed valve** |
| **Submersible pump** | Pump + motor that work **under** water (in wet wells) |
| **Impeller** | The spinning part inside a centrifugal pump |
| **Volute / casing** | The housing around the impeller |
| **Suction** | The pump's inlet side |
| **Discharge** | The pump's outlet side |
| **Head** | Height (energy) a pump can push water up — measured in m or ft |
| **Priming** | Filling a pump with liquid before starting |
| **Cavitation** | Bubbles forming and collapsing inside a pump — sounds like gravel; causes damage |
| **Packing** | Rope-like seal around a pump shaft; should drip slightly |
| **Mechanical seal** | Precision seal around the shaft; should **not** drip |
| **Bearing** | Supports a turning shaft and reduces friction |
| **Coupling** | Connects motor shaft to pump shaft |
| **Valve** | Device that starts, stops, or controls flow |
| **Gate valve** | Fully open or fully closed (isolation) — don't throttle |
| **Globe valve** | Good for throttling (controlling flow) |
| **Butterfly valve** | Disc that turns ¼ turn — isolation or throttling |
| **Check valve** | Lets water flow only **one way** — prevents backflow |
| **Plug valve** | ¼-turn valve good for sludge |
| **Blower** | Machine that pushes air (for aeration) |
| **Diffuser** | Device at tank bottom that releases air bubbles |
| **Motor** | Turns electricity into rotation |
| **VFD** | Variable Frequency Drive — changes motor speed |
| **Breaker / fuse** | Protects circuits from too much current |
| **Overload (relay)** | Protects a motor from overheating from too much current |
| **Generator / auxiliary (standby) power** | Backup electricity during power outages |
| **Flowmeter** | Measures flow (Parshall flume, magnetic meter) |
| **Sensor / probe / analyzer** | Measures something automatically (DO, pH, level) |
| **SCADA** | Supervisory Control And Data Acquisition — computer system that watches and controls the plant remotely |
| **PLC** | Programmable Logic Controller — the small computer that runs equipment automatically |
| **Telemetry** | Sending data long-distance (e.g., from a lift station to the plant) |
| **Calibration** | Adjusting an instrument so it reads correctly |
| **Setpoint** | The target value a controller tries to keep (e.g., DO = 2 mg/L) |
| **Preventive maintenance (PM)** | Scheduled maintenance **before** something breaks |
| **Corrective maintenance** | Fixing something **after** it breaks |
| **Lubrication** | Grease/oil to reduce friction |

## Part G — Safety words

| Term | Plain meaning |
|---|---|
| **PPE** | Personal Protective Equipment (gloves, glasses, boots) — **last** line of defence |
| **Hazard** | Something that could hurt you |
| **Confined space** | Enclosed space not meant for people to work in, with limited entry/exit (wet wells, tanks, manholes) |
| **Atmospheric testing** | Testing the air with a gas detector **before** entering |
| **LEL** | Lower Explosive Limit — the lowest amount of gas that can explode |
| **H₂S** | Hydrogen sulphide — rotten-egg gas, toxic, heavier than air |
| **Methane (CH₄)** | Explosive gas from digesting sludge, lighter than air, no smell |
| **Oxygen deficiency** | Not enough oxygen to breathe (below 19.5%) |
| **SCBA** | Self-Contained Breathing Apparatus (air tank on your back) |
| **Lockout (LOTO)** | Locking equipment off so it can't start while you work on it |
| **SDS** | Safety Data Sheet — information about a chemical's dangers |
| **WHMIS** | Canada's chemical-hazard information system (labels, SDS, training) |
| **IDLH** | Immediately Dangerous to Life or Health |
| **Attendant / standby person** | Person who stays **outside** a confined space to watch and call for help |
| **Near miss** | Incident where nobody got hurt but could have — still report it |
