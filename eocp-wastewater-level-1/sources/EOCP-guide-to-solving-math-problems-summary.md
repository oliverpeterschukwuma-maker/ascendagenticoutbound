**Source:** *Logical Math Problem Solving / A Guide to Solving Math Problems* (4 pages, EOCP). One long worked word problem (centrifuge run time) used to teach a method.

## Key ideas
- There is **no "super formula"** for word problems — break them into small pieces.
- **Wrong approach:** calculating everything you can from each sentence in order ("unstructured").
- **Right approach: work backwards** — read it all once, then start from the **question**, find the information with matching **units**, and only then calculate.
- **Use units as clues;** "**per**" means **divide**.
- Questions often include **extra information on purpose** (e.g., pH and DO in a detention-time question) — but some details tell you *which* formula applies, so don't throw things away too quickly.
- **Show your work** forwards once you have the plan.
